## 面试时需要讲清楚

1. **为什么分三份数据？** 训练拟合模型，验证选择候选和阈值，测试只用于最终报告。插补、标准化和编码都不能先在全量数据上拟合。
2. **为什么用 AP？** 它关注排序与召回过程，且依赖流失基准比例；所以同时报告 prevalence、ROC-AUC、Brier 和 top-20% lift。
3. **为什么需要逻辑回归？** 提供成本低、易解释的比较基线，避免只展示一个复杂模型。
4. **SHAP 是否说明因果？** 不能；它解释模型分数。贡献单位是 log odds，相关变量会分摊贡献。
5. **为什么不让 Airflow 自动覆盖 API 模型？** 训练成功不代表值得上线。当前通过评估产物哈希验证和显式选择完成本地部署切换，后续可加入业务阈值和模型注册。
6. **能否说模型能留住客户？** 不能，流失倾向不等于干预响应。需要随机对照实验和扣除优惠/触达成本后的留存利润。
7. **还缺什么？** 真实时间外验证、数据新鲜度与漂移监控、模型注册、部署授权和真实干预效果验证。
